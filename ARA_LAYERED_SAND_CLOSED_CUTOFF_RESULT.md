# ARA Layered Sand Closed Cutoff Result

Run date: 2026-05-26

## Purpose

Correct the prior visual workbench failure:

```text
old shifted view = future observed terrain -> formula -> shifted backward
```

This script performs the actual autonomous test:

```text
observed data until cutoff
-> seed formula state
-> generate future NINO/SOI/PDO internally
-> compare generated path to truth
```

Script:

```bash
python TheFormula/ara_layered_sand_closed_cutoff_run.py
```

Visualizer:

```text
TheFormula/ara_layered_sand_closed_cutoff_viz.html
```

## Leakage Guard

For each cutoff:

- observed NINO/SOI/PDO are available only through the cutoff date;
- after the cutoff, NINO is generated one month at a time by the layered formula;
- after the cutoff, SOI/PDO are generated by a pre-cutoff partner closure;
- actual post-cutoff NINO is used only for scoring and plotting truth;
- no future-origin shifted formula values are used.

The SOI/PDO closure is intentionally simple:

```text
SOI = 0.72 previous SOI + 0.28 pre-cutoff anti-phase target from predicted NINO
PDO = 0.96 previous PDO + 0.04 pre-cutoff slow-reservoir target from predicted NINO
```

## Interpretation

The user's criticism was correct: the earlier shifted visual branch was a past/terrain generator indexed by future observations, not a closed prediction engine.

This closed run is the first version in this branch that actually cuts the data and lets the formula run. It does not reproduce the near-perfect shifted-terrain match. Some presets beat flat cutoff persistence on some cutoffs, but the autonomous path is not yet a solved predictor.

The key distinction is now explicit:

```text
Terrain mapper / nowcaster: works strongly once observed data at t exists.
Closed predictor: still weak and sensitive to closure rule and preset.
```

The next work should focus on the internal state evolution rule after cutoff:

```text
predicted NINO/SOI/PDO/contact state at t
-> next tick state
```

not on shifting observed future terrain backward.
