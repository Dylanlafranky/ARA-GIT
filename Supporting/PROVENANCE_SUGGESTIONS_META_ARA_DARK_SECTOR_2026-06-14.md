## Main recommendation

Add a short `Data, constants, and calculation provenance` section immediately
before `The Formula`, followed by a compact provenance column or numbered
endnotes in the two results tables.

Every number should be labelled as exactly one of:

1. `External measured/inferred input`
2. `Framework-defined landmark`
3. `Derived from external inputs`
4. `Framework prediction`
5. `Exploratory fitted result`

This prevents a reader from confusing Planck Collaboration cosmological
parameters with Planck's physical constant, or a fitted diagnostic with a
parameter-free prediction.

## Important terminology clarification

The dark-sector paper does not use the physical Planck constant
`h = 6.62607015e-34 J s`. It uses cosmological parameters reported by the
Planck Collaboration satellite analysis.

If the phrase `Planck constant` is intended literally in another document, use:

```text
h = 6.62607015 x 10^-34 J s, exact by SI definition
```

Local implementations include:

- `archive/numbered_tests/04_atomic_clock_transitions.py:12`
- `archive/numbered_tests/53_fundamental_physics_ara.py:30`

Primary source:

- BIPM, SI defining constants:
  https://www.bipm.org/en/measurement-units/si-defining-constants

For this dark-sector document, call the other values `Planck 2018 cosmological
parameters`, not `Planck constants`.

## Formula-result provenance

### Final fixed formula

The fixed formula uses:

```text
DE + DM + b = 1
DE / DM     = phi^2
DM / b      = phi^(7/2)
```

Therefore:

```text
DM = 1 / (phi^2 + 1 + phi^(-7/2))
DE = phi^2 * DM
b  = DM / phi^(7/2)
```

### Why `7/2 = 3.5`

The three candidate derivations are explored in:

- `243BL7_origin_of_3point5.py:140-200` - golden-angle overshoot
- `243BL7_origin_of_3point5.py:580-625` - additive horizontal/vertical path
- `243BL8_meta_ara.py:176-230` and `:510-540` - pipe plus crossing remainder

The numerical identities are:

```text
golden angle = 360 / phi^2 = 137.507764 degrees
2 * phi = 3.236067978
3.5 - 2 * phi = 0.263932023
(7 - 4 * phi) / 2 = 0.263932023
phi^3.5 = 5.388361704
```

Recommended provenance wording:

> The identities are exact mathematical consequences once `7/2` is selected.
> Script 243BL6 first identified a fitted exponent near `3.477`; scripts 243BL7
> and BL8 then tested `7/2` as the proposed structural value. Present the
> structural interpretation as a hypothesis supported by the numerical
> proximity, not as an independent empirical derivation.
