Order
The shuffle keeps the identical set of primes and gates and only destroys their sequence. Marginal distributions are unchanged. Anything that survives the shuffle was never sequential structure.
Skeleton
Fixed skeleton. The ridge is A = 1. The seam is where A = 0 and A = 2 meet — the two poles are one point once the diameter is wrapped. Radius is log₂ q, so every octave of gate size is an equal radial step. Height is parent index.

Nothing is fitted per gate. Each gate q admits exactly q−1 positions, mirror-symmetric about the ridge, because r ↔ q−r is a fixed-point-free involution (Thm 26). Gate q = 2 sits exactly on the ridge for every odd prime — the only exact 1.0 readings in the field.
