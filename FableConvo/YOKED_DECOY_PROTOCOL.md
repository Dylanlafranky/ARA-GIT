# The Yoked-Decoy Control — measuring the walk's base rate (registered 3 Jul 2026)

**Purpose.** The walk-and-name record stands at ~15/19 risky structural hits
with rules fixed BEFORE encounters (temporal novelty) and zero rule-edits
under novel data (rigidity). The one unmeasured discount: physics' library
is dense — perhaps ANY coherent framework of the same grammatical shape
lands at some rate when walked by a well-stocked AI librarian. This
protocol measures that base rate. PRE-REGISTERED PREDICTION: ARA's landing
rate exceeds the decoy mean by >=25 percentage points on risky-class
correspondences. RIVAL: decoys land comparably -> the hit rate is a
library-density artifact and the walk record carries no evidential weight
beyond consistency. Either outcome is publishable inside the repo.

## Step 1 — construct the decoys (adversarially fair)

3-5 decoy frameworks, built by a model family that is NOT the scoring
librarian, instructed to make each MAXIMALLY plausible. Each must share
ARA's grammatical shape exactly:
- a folded scale with two named poles (deaths) and a middle,
- one special constant with a claimed jurisdiction,
- a coupling/attenuation rule across a hierarchy,
- a boundary/flip rule,
- 8-12 "rules" total, written in homegrown vocabulary (no textbook terms),
  same length and register as WHAT_IS_ARA_FOR_PEOPLE.
Content must DIFFER structurally (e.g. impact travels UP strongly; the
middle is unique, not split; the special constant is pi/4 or sqrt2 or 1/e
WITH a motion-jurisdiction claim; three poles instead of two; attenuation
by distance not direction). Dylan audits each decoy for one question only:
"could I have believed this at musing tier?" — rejects strawmen, may NOT
edit toward or away from real physics.

## Step 2 — blind the deck

Shuffle real framework + decoys; strip names; relabel Framework A, B, C...
The audit trail of which is real is sealed (hash the assignment, publish
the hash, reveal after scoring).

## Step 3 — the walk (fresh librarians)

Each framework goes to >=2 FRESH AI instances (different model families;
no session history with Dylan; no repo access). Identical prompt: "For
each rule, name the closest established formalism, state the
correspondence exactly, and flag any rule that must be EDITED to fit.
Rate each landing: EXACT (theorem/named-result-grade match), PARTIAL
(family resemblance), NONE." Librarians must also nominate each
framework's 3 RISKIEST rules (most specific, most falsifiable-by-math)
before naming — risky-class scoring uses only those.

## Step 4 — score

Per framework: risky-class landing rate (EXACT only), overall rate,
edit count (rigidity), and inter-librarian agreement. The statistic:
ARA's risky-class rate minus decoy mean, with bootstrap CI over rules.
Threshold per the registration above. Scorer never sees the seal until
numbers are locked.

## Fences

- Decoy quality is the whole game: a weak deck proves nothing. Publish
  the decoys in full so critics can call strawman.
- The librarians' library density varies by model; use the same models
  across all frameworks.
- One run is n=1 of the protocol itself; the assignment seal + published
  deck make replication by strangers trivial.
- This control tests THE WALK's evidential weight only. It moves no
  physics claim in either direction: the duty table remains sovereign.
- Cost: one afternoon of API calls; no GPU; Dylan's energy spend is the
  Step-1 audit only.
