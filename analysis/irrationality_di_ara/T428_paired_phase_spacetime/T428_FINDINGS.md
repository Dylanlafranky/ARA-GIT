# T428 findings — corrected paired-phase spacetime Di-ARA

## Frozen result

The primary paired-phase claim was **not supported**.

- whole-window closure gate: 0/5 holdouts;
- persistent local coupled run: 5/5;
- independent H1/L1 agreement: 5/5;
- matched-event H1/L1 beats wrong-event pairings: 55% (gate 75%);
- circular chronology control: 4/5 at p <= 0.05.

No gate was changed after scoring.

## What the correction established

T427 had flattened two leading-side observables into one apparent pair. T428
measured four candidate sides separately. The connection pair (spectral
concentration versus effective spectral width) opposed consistently across all
five holdouts, with Spearman correlations from -0.296 to -0.545. The traversal
pair (spectral movement versus complex persistence) did not show global
opposition; correlations ranged from -0.006 to 0.113.

The coupled system repeatedly entered short low-gap states. Four of five event
histories lost the frozen result when the two B-side histories were circularly
shifted, so local chronology matters. However, event-window closure was not
better than matched off-source windows, and matched detector pairs scarcely
beat wrong-event pairings. The measured local organization is therefore not
identified with the binary-black-hole handover.

## Post-result timing diagnostic

An explicitly exploratory diagnostic tested whether the persistent low-gap runs
were concentrated at the published event time. They were not: only 1/5 events
had a persistent run within +/-64 ms, while runs recurred throughout the
pre-event history. This diagnostic does not alter the frozen verdict.

## Current ARA interpretation

The cleanest supported reading is a recurring local child-scale relation in the
processed strain histories. It does not yet identify the parent/rung that owns
that relation. The connection pair is usable as a measured opposition; the
traversal anti-phase remains unresolved or is being observed at the wrong scale,
lag, or cut.

## Next test

Freeze an event-locked short window from an independent development event using
an external native strain landmark, not an ARA-selected crossing. Compare the
same four-coordinate path against identically placed off-source and wrong-event
windows. Require an event-specific closure improvement and reproducible direct
or lagged traversal opposition. If that fails, retire complex persistence as
the candidate traversal anti-phase for this dataset.
