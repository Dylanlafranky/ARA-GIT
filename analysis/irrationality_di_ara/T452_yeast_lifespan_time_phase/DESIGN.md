# T452 report design

## Audience and reading path

Technical, methods-first report for a framework author who needs to see the raw measurements, relational address, transformed geometry, transfer checks, independent witnesses, and limitations without inferring axis meanings.

## Visual system

- White/near-white report surface with charcoal text and quiet grey guides.
- Development is blue, untouched same-platform holdout is orange, and the separate-platform external cohort is olive.
- Pure/equal-progress references are dark neutral and dashed.
- Every chart states the measured unit, 0–2 coordinate meaning, cohort, and denominator in its title, subtitle, axes, or adjacent explanation.
- Color is reinforced by explicit cohort labels and table values.

## Chart map

1. Raw lifespan relationship — scatter — observed G1 count versus observed hours, one dot per mother cell.
2. Elapsed phase path — line — median elapsed clock coordinate versus generation-built maturity.
3. Counter-phase TE-ARA sum — line — maturity plus remaining-time coordinate, pure reference at 2.
4. Signed time shadow — line — elapsed clock minus maturity; forced endpoint zeros are stated.
5. Local time child — line — division interval divided by the same cell's mean, ridge at 1.
6. Local time child ARA — line — parameter-free reciprocal 0–2 map of the same rate.
7. Size witness — line — cell area relative to starting area.
8. Rpl13A concentration witness — line — fluorescence concentration relative to start.
9. Total Rpl13A witness — line — area times concentration relative to start.
10. Witness alignment — bar — same-maturity curve correlations with the local time child.

## QA surface

The canonical artifact is packaged into a self-contained HTML report. Static PNGs are supporting visual QA and individual-detail views, not the report runtime.
