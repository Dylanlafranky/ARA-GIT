# T449 report design

## Surface

Technical analytical report for the Codex desktop report renderer.

## Information order

1. Result-first statement distinguishing recovered structure from the failed directional claim.
2. Metric strip for scope, eligibility and frozen temporal result.
3. Exact relational address and definitions.
4. Chronological controls and frozen gates.
5. Parent/common versus child/differential geometry.
6. Direction-split post-frozen diagnostic.
7. Data-quality table, limitations and the next time-facing biologic cut.

## Visual encoding

- Blue: temporal retention child \(C_A\).
- Orange: traversal/renewal child \(C_B\).
- Purple: common parent-facing mode.
- Teal: differential child mode.
- Green: passed confirmatory evidence.
- Red: failed or non-directional evidence.

All axes retain units and all charts include an adjacent interpretation. Confirmatory and post-frozen results are visibly separated in prose.
