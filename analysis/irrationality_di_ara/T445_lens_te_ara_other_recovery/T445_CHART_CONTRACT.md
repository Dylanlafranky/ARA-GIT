# T445 chart contract

Delivery surface: one self-contained technical HTML report generated from canonical `artifact.json`. Static PNGs are supporting QA previews, not a second report.

## Visual 1 — Native Fermat decomposition

- Question: do geometric path and gravitational-potential terms reconstruct each observed differential delay in native units?
- Form: grouped bars with uncertainty intervals represented in the accompanying table and narrative.
- Grain: image pair (AB, AC, AD) × contribution (geometric, potential, total, observed-required).
- Takeaway boundary: show sign and scale; do not equate agreement with a new physical law.
- Palette: blue for geometric/traversal, orange for potential/connection, charcoal for total, pink for observed-required.

## Visual 2 — Controlled shear path in the A/B plane

- Question: when the explicitly modelled shear is turned from absent to fitted strength, does the observed-required relation lie along that pair path or away from it?
- Form: faceted scatter/line data by image pair; native arcsec² and 0–2 contribution-share versions.
- Grain: image pair × shear fraction \(\lambda\) in 0.025 increments; fitted endpoint and observed-required point retained as labelled rows.
- Takeaway boundary: \(\lambda\) is a controlled counterfactual coupling coordinate, not chronological time.
- Palette: one blue root for the path, orange endpoint, pink observed-required; markers and point types duplicate color distinctions.

## Visual 3 — Tangent/normal Other decomposition

- Question: how much of the endpoint mismatch is along the known shear path versus perpendicular to it?
- Form: diverging grouped bars plus exact audit table.
- Grain: image pair × residual component; clean blind pairs AB/AD distinguished from AC’s model-informed sign choice.
- Takeaway boundary: parallel means advance/lag along this one tested coupling; perpendicular means unresolved model direction, not a named force.
- Palette: blue for parallel/movement, orange for perpendicular/connection; signs labelled directly.

## Visual 4 — Model astrometry and source lock

- Question: does the published-summary median lens reconstruct one common source from all four observed image positions before delay data are introduced?
- Form: image-plane scatter with lens centre, images, and back-projected source points; a compact residual table provides exact values.
- Grain: image component A–D.
- Takeaway boundary: this is a reconstruction from published marginal summaries, not the missing full posterior.
- Palette: blue images, orange source reconstructions, charcoal lens centre.

## Data sufficiency and fallback

- Four image components are intentionally labelled rather than treated as a population scatter.
- Three image pairs are intentionally shown as exact labelled comparisons rather than an inferential sample.
- The controlled path has 41 observed calculation points per pair and is suitable for a line/relationship view.
- If the published-summary model cannot source-lock the four images within 0.02 arcsec RMS, stop before interpreting the delay residual geometry.
