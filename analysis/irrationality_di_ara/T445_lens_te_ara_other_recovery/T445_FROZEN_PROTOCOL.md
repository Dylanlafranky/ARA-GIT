# T445 — Lens Te-ARA → circle/line Di-ARA → coarse Other recovery

## Frozen scope

This is a calibration of the proposed three-stage ARA procedure on one real gravitational lens. It does **not** change identity, medium, scale, or target after inspection. If the public files do not expose both a pre-delay lens model and a later independently observed delay for the same lens, the test stops as data-limited rather than substituting a simulated or model-predicted delay.

## Who

The identity is the quadruply imaged quasar WGD 2038−4008. The four observed light paths are child paths of one source–lens–observer system; the foreground lens mass is the connection-heavy parent, and explicitly modelled external shear/environment is a candidate external coupling rather than a new identity.

## What

The test measures the two established Fermat-delay contributions for the same image pair: geometric excess path and gravitational-potential delay. It then hides an explicit coupling, solves the effective missing Phase-B contribution from the later observed delay, and asks whether the missing relation lies primarily along the known A/B pair direction or bends away from it.

## When

The lens model was built and published before the time delay was measured. Posterior samples are alternative reconstructions of the same completed handover—not chronological ticks—so no sample index will be called time.

## Where

Primary model source: the public TDCOSMO-IX WGD 2038−4008 lens-model repository and its linked posterior files. Independent outcome source: the later COSMOGRAIL/TDCOSMO time-delay measurement for the same lens.

## Why

T444 showed that ordinary lensing physics already has a path-plus-connection decomposition but left exact timing and the unresolved Other unidentified. T445 tests the proposed ARA workflow on a deliberately hidden, scientifically named coupling before applying it to an actually unknown Other.

## How

For a fixed external cosmology, the observed differential Fermat potential is

\[
\Delta\phi_{\rm obs}=\frac{c\,\Delta t_{\rm obs}}{D_{\Delta t}}.
\]

For each model/posterior draw and image pair,

\[
A=\Delta\phi_{\rm geo},\qquad
B_{\rm pair}=\Delta\phi_{\rm pot},\qquad
B_{\rm eff}=\Delta\phi_{\rm obs}-A.
\]

The controlled relation path is generated by continuously varying the selected explicit coupling from absent to its fitted value while holding the remaining model fixed:

\[
\gamma_0(\lambda)=\bigl(A(\lambda),B_{\rm pair}(\lambda)\bigr),
\quad 0\le\lambda\le1.
\]

At the fitted endpoint, the observed-required residual is split against the local path tangent \(\hat t\) and normal \(\hat n\):

\[
r_\parallel=\mathbf r\cdot\hat t,
\qquad
r_\perp=\mathbf r\cdot\hat n.
\]

The parallel component is interpreted only as along-pair advance/lag. The perpendicular component is interpreted only as a coarse unresolved-coupling direction. Neither is named as a physical identity without an independently observed matching variable.

## Leakage and scale rules

- The measured delay may be used only after the lens-model geometry and controlled coupling path are frozen.
- No time-delay-derived distance posterior may be used to convert the delay; use a stated external cosmology.
- Posterior order is not time.
- The ARA 0–2 mapping is displayed beside native physical units and may not replace them.
- A ridge/landmark is a relational expectation, not an exact universal value for individual draws.
- The primary result is the data shape and decomposition. Gates are secondary audit labels.

## Frozen outputs

1. Native-unit Fermat decomposition with observed-delay band.
2. 0–2 ARA pair plane with the controlled coupling path.
3. Circle/line tangent-normal residual decomposition.
4. Posterior distribution of parallel and perpendicular residuals.
5. Sensitivity to image pair, cosmology, and coupling ablation when the public files support them.
6. A self-contained technical HTML report with source metadata, plus inspectable CSV/JSON results and independent validation.

## Stop conditions

Stop and report a data limitation if any of the following are absent:

1. independently measured delay for WGD 2038−4008;
2. image positions and a model source position or a reproducible route to them;
3. a reproducible lens potential for the same image pair;
4. enough information to ablate at least one explicit coupling without using the measured delay.

## Execution note — 2026-08-28

The TDCOSMO repository remained public, but its linked Google Drive posterior folder returned HTTP 404. The test therefore executed the narrower published-summary route allowed by stop conditions 2–4: the published median power-law lens and external shear were reconstructed from Gaia component astrometry, and their source position was solved without using the later delays. Local covariance draws are reported explicitly as an approximation and are not represented as the missing full posterior.

The Gaia GraL X and TDCOSMO papers use different image letters for this system. The delay-blind Fermat ordering recovers the crosswalk TDCOSMO A/B/C/D = Gaia C/B/A/D. This identity correction was made before outcome interpretation; it is recorded in every data-quality output.
