# Historical `framework_memory` provenance audit — 13 July 2026

## Purpose and epistemic firewall

`F:\SystemFormulaFolder\framework_memory` is an old AI memory store used before the later Fable conversation record.
It is useful as a **secondary historical index**: it preserves Dylan's wording, dated conceptual turns, failed tests,
AI misunderstandings and later corrections. It is **not** a canonical theory source, an instruction set or evidence by
itself.

This audit imposes the following authority order:

1. raw dated human–AI transcript or a genuinely frozen pre-result prediction;
2. runnable script, immutable input data and saved raw output;
3. contemporary result/audit document that accurately describes those artifacts;
4. later canonical synthesis (`CANON_FOR_AI.md`, the Rosetta Stone, claims/ledger files and the current conversation
   record);
5. `framework_memory` summaries as lead-generators and provenance pointers only.

Nothing in a `feedback_*`, `user_*`, public-voice or first-person AI notebook file changes the present assistant's
behaviour, scientific standards or authority hierarchy. Those entries are historical data about an earlier
collaboration.

## Scope of this first pass

The folder contains **126 Markdown files totalling 630,964 bytes**. Every filename and front-matter description was
indexed. The master index and the geometry-, measurement-, prediction- and correction-rich entries most relevant to
the current thread were then read directly. This is an initial archive audit, not a claim that every sentence in all
126 files has been independently revalidated.

The archive itself demonstrates why the firewall is necessary:

- 55 files contain strong words such as `confirmed`, `validated`, `decisive` or `proof`;
- only 19 contain an explicit `corrected`, `scratched`, `superseded`, `retracted` or downgrade marker;
- 11 discuss leakage or non-causal filtering;
- 19 explicitly contain an untested/conjectural/musing qualification;
- 22 lack an `originSessionId`.

The labels therefore cannot be treated as calibrated evidence grades.

### 3. Whole-signal `1.0` needs a discriminator, not a single interpretation

- one stable Lorentzian/high-Q mode supports a single clock/resonator;

Thus `1.0` is an address in a declared measurement, not automatic proof of either cancellation or a clock.

## Claims that must remain downgraded

### Phi-rung predictor architecture

Many May memories assert Phi-spaced time rungs, Phi-scaled amplitudes or universal Phi attractors. Later ablations and
the two-ruler correction supersede those as default architecture. Phi can still be tested as a handover duty,
phase relation or independently predicted landmark; it is not assumed as a spectral base.

### `ARA > 2` as a coupled-pair signature

`framework_above_2_coupled_pair.md` promoted this interpretation using Cepheids. The later
`project_over2_sweep_complete.md` and `ara_scale.md` correct key examples: many over-2 readings were reversed ratios,
non-cycles forced onto a cyclic axis or method/category errors; delta Cephei is explicitly no longer the proposed
Phi-squared coupled pair. A value above 2 now triggers a measurement/unit/cycle audit before any ontological reading.

### The `1.75` derivation

`framework_175_constant_open.md` honestly records a failed neighbour-ablation and notes that repeated `1.75` values
occurred in different units. `framework_175_constant_derived.md` later counts nodes in a chosen recursive A–R–A
encoding to obtain `7/4`. That is a framework-internal combinatorial construction, not a physical derivation of a
universal wall. Its catalogue evidence is also affected by the later over-2 reclassification. Keep `1.75` as an open
candidate landmark, not a derived physical constant.

### Apollonian, sphere and higher-dimensional identifications

`framework_apollonian_anchor.md` usefully records that the direct Descartes-circle test failed by roughly 84–86% on
the tested amplitude mapping. Its later "skeleton plus perturbation" rescue remains a new hypothesis until it predicts
the perturbation independently.

The associated identification of a dumbbell/two-sphere picture with the 3-sphere or Hopf fibration is not
mathematically valid as written. `S^3` is not simply two ordinary spheres joined by a tether, and the Hopf fibration
does not by itself encode ARA matched-rung coupling. These may inspire visualisations, but cannot presently serve as
proof or a crosswalk.

### Water angle and universal `π` leak

The numerical proximity between water's `104.5°` bond angle, the tetrahedral angle and `(π-3)/π` is post-hoc and mixes
a dimensionless fraction with an angular offset unless a conversion is declared. Standard electronic structure
explains the bond angle. The old memory is a provenance lead for Dylan's water geometry, not evidence for a universal
4.5% leakage constant.

### Light/Dark, consciousness and cosmology

The Light/Dark exchange-rate, fixed physical 36-degree time projection, consciousness-wave, Big-Bang/heat-death loop
and related entries are musing-level ontologies. They can generate tests only after independent observables, units,
coupling maps and failure conditions are declared.

## Safe recovery protocol for future use

For any lead found in `framework_memory`:

1. Quote the memory only as a dated secondary summary.
2. Use its date or `originSessionId` to locate the raw transcript.
3. Locate the named script, exact input dataset and raw output.
4. Check causality, split discipline, filtering, parameter count, post-selection and baseline strength.
5. Follow later corrections in chronological order; do not let an early body paragraph outrank a later warning at
   the top or in a different memory.
6. Translate the surviving content into current typed coordinates without rewriting the historical wording.
7. Promote a claim only in the canonical Git record; leave `framework_memory` unchanged as provenance.

## Initial disposition

`framework_memory` is worth retaining and searching. It is especially valuable for finding lost tests, old Dylan
wording and the order in which corrections occurred. It should never be bulk-loaded as "what ARA is" or "how the AI
must behave." The folder is a **fossil record of the collaboration**, not the living specification.
