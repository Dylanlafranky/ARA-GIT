# T360 public-source record

## Experiment

Georgia Tech Nonlinear Dynamics Laboratory, **Plinko dynamics** (Group 2).

- Project page: https://nldlab.gatech.edu/w/index.php?title=Group_2
- Source report: https://nldlab.gatech.edu/w/images/4/48/Cordell_Group2_Phys6268.pdf
- Public experiment video: https://www.youtube.com/watch?v=Tmf18EciFQs

The experiment uses a sliding magnetic puck carrying a white tracking sphere on a tilted board containing 28 attracting magnets in five rows. The authors report 100 runs from each of four nearby starting regions (400 physical runs total). The original laboratory camera operated at 200 fps. The only individually visible public record located for T360 is a compressed 480 x 360, 15 fps video derivative containing five sequential drops.

## Frozen limitations

1. The public video is downsampled to 15 fps; the experiment's 200 fps timing is not recoverable from it.
2. The video contains accumulated coloured path overlays. T360 tracks only the active compact white marker; coloured trails are never scoring truth.
3. The 400-run image is aggregate ink, not 400 recoverable chronological trajectories.
4. The system is magnetic Plinko. It calibrates continuous connection/steering, not discrete ball-peg collision microphysics.
5. The five public paths and the aggregate image come from the same experiment. This is a within-experiment calibration, not external replication.
