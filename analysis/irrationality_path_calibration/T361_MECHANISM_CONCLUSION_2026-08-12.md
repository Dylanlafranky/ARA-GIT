# T361 mechanism conclusion — what the Irrationality Di-ARA recorded

## Answer

In this controlled physical oscillator archive, the tested Irrationality Di-ARA recorded the **local two-wave movement** accurately, but did not autonomously restore every complete hidden wave from one entry lock.

The first 60% of each raw physical pair created a relation table on two 0–2 ARA diameters. It retained parent position, child position, visible-parent movement and the four causal direction states. On the untouched final 40%, that table recovered the next child location with median error `0.018–0.042` ARA units and the next child direction with `92.7–97.5%` agreement in every one of the nine physical conditions.

Removing the direction quadrant raised local next-position error to `0.114–0.137` in the outer regimes. The four-state Di-ARA therefore carried real movement information there; it was not merely decorative bookkeeping.

However, recursively using each predicted child location as the next lookup address caused small errors to compound. Full-cycle restoration passed the frozen absolute waveform, movement and closure requirements only in the adjacent `150, 170, 190` ohm band. At `170` ohm, complete hidden-wave recovery reached:

- waveform correlation `0.9929`;
- RMSE `0.0689` ARA units;
- direction agreement `96.83%`;
- quadrant agreement `96.77%`;
- endpoint error `0.0212` ARA units.

Outside the coherent band, complete-cycle correlations became slightly negative even though one-step recovery remained accurate. This shows a navigator/restorer distinction:

> The present Di-ARA tells us the next local movement well when its current relation is known. It does not yet guarantee that a long hidden path stays on the correct branch without renewed relational information.

## How this relates to future testing

The next direct question is no longer whether the local Di-ARA records waves—it did so across this archive. The next question is how often a new information lock is needed as address opening increases.

A future frozen test should reveal the true child coordinate only at predeclared intervals, such as every 2, 4, 8, 16 or 32 readings, then measure how restoration error grows between locks. The prediction suggested by T361/T361B is:

- closed/coherent regimes tolerate longer gaps between locks;
- open-address regimes require more frequent locks;
- `x_P`, closure history and possibly a parent-rung coordinate should estimate the safe lock interval.

That would test whether the Irrationality Di-ARA not only records movement, but also reports its own recovery horizon.

## Evidence boundary

This result concerns one controlled electrochemical oscillator archive. It supports a local relational recording function for the declared instrument. It does not prove universal ARA geometry, an exact irrational constant or unrestricted recovery of missing physical variables.
