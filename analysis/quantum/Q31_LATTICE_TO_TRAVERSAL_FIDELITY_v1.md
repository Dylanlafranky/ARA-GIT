### Plain restatement

local singularity those connections cease to be the main representation, but

counter-side as a locally ordered path that does not settle into stable

coherent traversal, `P_short(t)` be short-lag directional predictability and
`R_long(t)` be long-lag return/partner recurrence. Define, only when native
activity and `C+T` exceed frozen floors,

\[
x_{\rm Q31}(t)=\frac{2C(t)}{C(t)+T(t)}.
\]

The frozen qualitative prediction is:

\[
C_{\rm pre}>C_{\rm post},\qquad
T_{\rm post}>T_{\rm pre},\qquad
P_{\rm short,post}>\text{controls},\qquad
R_{\rm long,post}\leq\text{lattice control}.
\]

The proposed information thread is therefore “short-memory high, long-return
low”. The ARA crossing additionally requires `x_Q31` to move from above `1` to
below `1` around the external handover.

### Back-translation

Before the crossing, the same relations keep reconnecting to the same places.
After it, the relation continues to move in an ordered direction for a short
time but does not return to one durable partner. If it merely disappears,
randomises, or forms another stable network, this translation is wrong.
