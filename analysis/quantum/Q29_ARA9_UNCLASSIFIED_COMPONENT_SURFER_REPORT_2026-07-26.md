# Q29 — Nature of the ARA^9 Unclassified Component

**Orientation signature:** source-relation release at \(t\) → one-child
accumulation web at \(t+2\); residual sign retained; direct and flipped future
routes compared on the same simulator coordinate.  
**Date:** 26 July 2026  
**Status:** Exploratory characterization on the completely opened Q28 source  
**Validated:** PASS, 38/38 independent checks

## Result first

The Q28 remainder is **not currently supported as an independently coherent
Phase B**. It is also **not an unstructured numerical leftover**.

The best evidence-supported description is:

> **Local signed z-axis handover memory; no stable counterpart detected.**

Plainly: after the Q28 parent-to-child flip, about 10% of the later relation is
left unexplained. Roughly 95% of that remainder lies on one coordinate. That
signed coordinate has a strong one-slice echo and stays unusually close to the
same endpoint neighbourhood. However, it does not keep returning to one stable
partner, and the complete three-coordinate residual shape does not travel.

This places it between Dylan's two proposed interpretations. It behaves more
like a **short-lived, child-mediated handover correction** than a separate
Phase B wave, while remaining more organized than arbitrary residual children.

## The distinction tested

Three descriptions were kept separate:

1. **Coherent counterpart:** the residual should recur as a complete shape,
   repeatedly select a stable relation partner, and preserve a reproducible
   direct-or-flipped route.
2. **Residual children / nearby connections:** the residual should remain
   locally attached to active endpoint relations without preserving one
   independent partner.
3. **Unstructured remainder:** neither its amplitude nor its route should beat
   equally permissive displaced controls.

The component was deliberately not named Phase B before these tests.

## Data and method

Q29 reuses the public simulated source opened by Q27 and Q28:

- connected relation array: `2 × 100 × 500 × 66 × 3 × 3`;
- Q28 source-to-neighbour-web lag: 2 slices;
- eligible Q29 events: 76,043 across 400 branch/seed trials;
- development and later-half results remain separately reportable;
- every connected matrix in this source is exactly diagonal.

For each Q28 event:

1. The released source relation was transported to its one positively
   accumulating child using Q28's best positive-scale proper flip.
2. The unexplained vector was retained without calling it Phase B.
3. Its complete three-coordinate shape was searched across the relation
   lattice.
4. Because the remainder proved almost one-dimensional, its signed centred
   coordinate \(u_z=r_z/\lVert W\rVert\) was then surfed without any fitted
   scale. The identical ARA diameter reading is
   \(x_z=1+u_z\): `0` and `2` are opposite signed limits and `1` is the
   zero-residual ridge.
5. Direct and sign-flipped recurrence were both allowed.
6. Exact, seed-displaced, and time-displaced searches received equal candidate
   counts. A symmetric ±3-slice eligibility window corrected the deterministic
   sampler's arithmetic time phasing; mean exact-route jitter was 0.84 slices.

The later half was already open, so bootstrap probabilities measure stability
inside this source, not blind confirmation.

## What this does and does not establish

### Supported inside this source

- Q28's unexplained component is strongly axis-localized.
- Its signed amplitude contains short-lived trajectory-specific memory.
- The memory is coupled to the source endpoint neighbourhood.
- Its complete vector identity and stable partner are unresolved.

### Not established

- that the component is Phase B;
- that it is a new quantum object or hidden physical wave;
- that the z axis is physically privileged rather than simulator-coordinate
  specific;
- that this behavior occurs on quantum hardware;
- that TE-ARA closure has recovered an independently measured missing state.

The exact diagonality of this simulator remains the main limitation. It permits
only identity and 180° sign-flip geometry and cannot test a general off-axis
counterpart.

## Decisive follow-up

The next test should use a fresh source with non-zero off-diagonal connected
relations in a fixed shared coordinate frame. Before opening it, freeze:

1. a complete-shape recurrence threshold;
2. signed-axis recurrence against equal-search controls;
3. stable-partner persistence above both controls;
4. endpoint-route association;
5. direct versus flipped return;
6. a TE-ARA closure test using independently measured components.

A Phase-B interpretation should require the complete package, especially stable
partner identity and reproducible return. If an endpoint-neighbour inventory
predicts and removes the residual instead, the nearby-child explanation wins.
