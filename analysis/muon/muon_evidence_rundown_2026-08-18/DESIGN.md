# Design record

- Audience: technical reader needing a plain-language evidence ladder.
- Surface: MCP report artifact.
- Reading path: direct correction, population lead-up chart, evidence-grain table, individual-event boundary, conclusion and next test.
- Chart: one line chart showing the four T399 population landmarks in chronological order. It is not an individual trajectory.
- Table: one row per test family, retaining evidence grain, status and claim ceiling.
- Accessibility: explicit units, descriptive labels, no color-only status encoding, compact source-backed datasets.
