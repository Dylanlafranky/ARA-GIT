# T382 findings — RAL Silver ARA-native muon handover

Date: 2026-08-14  
Source class: P — aggregate time-by-detector histograms  
Primary implementation: 96-detector time-varying shares  
Verdict: `PARENT_RECOVERED_96_DETECTOR_CHILD_NOT_QUALIFIED`

## Answer first

The detector-summed muon population parent was recovered cleanly. The frozen
96-detector relation did not generalize as a stable traversal child, so this
source does not support the proposed child-pole/parent-ridge handover. It also
cannot test individual advance prediction because it does not link a named
muon's pre-decay state to that muon's daughter products.

This is a useful negative source/child result. It is not a failure of the parent
ARA coordinate and it is not a direct falsification of all possible muon-child
cuts.

## Parent result

The frozen parent coordinate was

\[
x_P(t)=2\left(1-e^{-t/\tau_P}\right).
\]

The calibration estimate was

\[
\tau_P=2.192800\ \mu\mathrm{s},
\qquad
t_{P,1}=\tau_P\ln2=1.519933\ \mu\mathrm{s}.
\]

The parametric-bootstrap 95% interval for `tau_P` was
`[2.192300, 2.193300] μs`. Every primary holdout beat the constant-count
baseline and its independently fitted ridge remained within the frozen 10%
drift limit.

## Candidate child result

The calibration-only 96-detector fit returned

\[
\widehat\gamma=0.013820000\ \mathrm{MHz/G}
\]

before the established coefficient was revealed. The later-revealed reference
was `0.013553896 MHz/G`, a relative difference of about `1.963%`.

That numerical proximity is not counted as child recovery because the spatial
relation failed its untouched controls:

- mean primary holdout gain versus no phase: `-0.974127`;
- detector-bootstrap 95% interval: `[-1.071427, -0.872500]`;
- correct detector-map gain: `-0.974127`;
- 95th percentile of wrong detector-map shifts: `-0.882234`;
- validation was not positive at every field;
- holdout was not positive at any primary field;
- one holdout reversed the declared orientation covariance.

Native, 2-bin and 4-bin sensitivity means were respectively `-0.974127`,
`-1.651022` and `-2.646633`. Rebinning therefore strengthened rather than
removed the failure.

The circular mean was `2.211404 rad`. It was closer to the `pi/2` landmark
than to the exact child pole `pi`, did not beat the matched random-phase
threshold, and did not beat the mirrored-origin control. Because C03-C05 had
already failed, these values remain a gradient description only and cannot be
used as handover evidence.

## Secondary release diagnostic

The detector-summed residual modulation gain averaged `0.010836` across the
three holdout fields. This is a small phase-associated residual and is retained
only as a diagnostic: incomplete detector acceptance can leak a spatial phase
pattern into the summed population curve.

## Data-quality verdict

All fourteen frozen files passed:

- source hash match;
- 96 × 2,048 shape;
- finite, strictly increasing native time axis;
- 0.016 μs native step;
- finite, integer, nonnegative counts;
- non-empty detector coverage in the analysis window;
- non-empty frozen analysis and background windows.

The failure is therefore not explained by corrupted files, missing detectors,
or an invalid time axis.

## Implementation provenance

The interrupted first executable compressed the detector field into the
official forward/backward banks. Audit showed that the frozen protocol required
all 96 detector shares. The bank result remains a labelled proxy diagnostic;
the conformance-corrected 96-detector execution is the primary verdict. Both
reached the same headline conclusion.

## Claim boundary and next source

The RAL Silver metadata orientation is longitudinal (`l`). That may make this a
poor source for a transported detector-phase child even though it is excellent
for the population parent. The clean next replication is an untouched,
same-medium transverse-field family with native detector geometry and a frozen
field ladder. Individual muon-to-neutrino timing still requires event-linked
parent and daughter data; no aggregate μSR archive can manufacture C16.
