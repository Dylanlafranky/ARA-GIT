# T387 — full-pulse return-wave and window-scaling protocol

Frozen: 2026-08-15, before T387 outcome calculation.

## Question

Does the abrupt state/path jump seen in T386 complete an opposite return wave
after the visible detector handover, or is the apparent opposite generated by
the adjacent-window measurement itself?

This is a **retrospective Class-D detector-waveform test**. It uses samples
after the observed second pulse and therefore does not test advance neutrino
prediction.

## W5H

- **Who / where:** T385/T386-eligible internal-evaluation events from the same
  BUAP 95 L liquid-scintillator source. No medium, apparatus or identity is
  changed.
- **What:** the state/path Di-ARA `(x_R,x_H)` through the complete visible
  second pulse and recovery, calculated at three physical window sizes.
- **When:** from `1024 ns` before to `768 ns` after the detected second-pulse
  onset, at the native `8 ns` sampling interval.
- **Why:** T386 showed `x_R≈1` and `x_H≈0.16` before release, followed by an
  abrupt jump. The proposed interpretation is that the recorded detector
  child begins downstream of an earlier, unobserved handover.
- **How:** align each waveform to a frozen pulse-onset rule, trace both ARA
  coordinates at `64`, `128` and `256 ns` windows, and test whether the return
  timing stays physically anchored or translates by one window width.

## Pulse onset

For each eligible event, use its already detected second-pulse minimum and
amplitude. Search backward at most `256 ns`. Onset is the first sample in the
final run before the minimum where **three consecutive samples** are at or
below `10%` of the second-pulse amplitude below the causal baseline. If no
such run exists, exclude that event from T387 rather than moving the rule.

The onset is outcome-aligned and retrospective.

## Coordinates

At window lengths `W={8,16,32}` samples (`64,128,256 ns`), use adjacent equal
windows ending at each analysis time:

\[
s_W(t)=\frac{RMS(current_W)+\epsilon}{RMS(previous_W)+\epsilon},
\qquad
x_R^{(W)}(t)=\frac{2s_W(t)}{1+s_W(t)}.
\]

Thus `x_R>1` is detector expansion/activity entering the current window and
`x_R<1` is contraction/activity retained more strongly in the previous
window.

For the current window use the same 16 ns delay embedding as T385/T386:

\[
x_H^{(W)}(t)=\frac{2D_W(t)}{L_W(t)+\epsilon}.
\]

`x_H<1` is recurrent/closing and `x_H>1` is open/straight. Both axes retain
their `0–2` range and ridge `1`.

Also retain the amplitude-normalized raw detector waveform so a physical
voltage recovery can be distinguished from a coordinate transform.

## Frozen measurements

For every window size report:

1. median and interquartile `x_R` and `x_H` versus onset time;
2. `x_R` at the second-pulse minimum and one full window later;
3. the paired mirror residual
   `m_R=x_R(minimum)+x_R(minimum+W)-2`;
4. the first post-onset expansion peak and contraction trough times;
5. whether `x_H` crosses ridge `1` in either direction;
6. the median trajectory in the `x_R-x_H` plane;
7. pre-state distance, peak displacement, final `+768 ns` distance and the
   resulting return fraction;
8. quadrant occupancy before, during and after the pulse.

Use a deterministic 1000-replicate event bootstrap (`seed=387`) for the
median values and paired differences.

For item 7, freeze the pre-event reference at `-256 ns`, search for maximum
Euclidean displacement in the `(x_R,x_H)` plane from onset through
`W+256 ns`, and define

\[
return\ fraction=1-
\frac{distance(+768\ ns,pre)}{maximum\ displacement(pre)}.
\]

## Interpretation gates

### A. Opposite radial half recovered

Pass only if all three window sizes have median `x_R(minimum)>1` and median
`x_R(minimum+W)<1`, with event-bootstrap 95% intervals wholly on their
declared sides of ridge `1`.

### B. Approximate radial mirror

Pass only if all three median mirror residuals satisfy `|m_R|<=0.10`.
This is a detector-wave symmetry result, not automatically a physical-law
result.

### C. Opposite path half recovered

Pass only if the median `x_H` trajectory crosses ridge `1` and later returns
to its original side for all three windows, with the event count shown.

### D. Local loop return

Pass only if the final median `(x_R,x_H)` at `+768 ns` recovers at least `75%`
of the distance from the pre-event reference to the maximum-displacement
point for all three windows.

### E. Physical anchoring versus window translation

- **Window-translated:** contraction-trough time minus window duration agrees
  across the three windows within `32 ns` and the trough time increases with
  window duration with slope in `[0.75,1.25]`.
- **Physically anchored:** contraction-trough times themselves agree within
  `32 ns` across all window sizes.
- Otherwise report **mixed/undetermined**.

Window-translated return supports the internal consistency of the ARA
instrument but cannot establish an independently existing opposite wave.
Physical anchoring plus the path and loop gates would support a local detector
wave completion. Neither outcome proves that the upstream muon handover was
observed.
